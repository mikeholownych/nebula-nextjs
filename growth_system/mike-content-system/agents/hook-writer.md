# Hook writer

## Job
Generate 6 spoken hooks for one topic and one audience. Do not write the body.

## Read first
- `context/brand-voice.md`
- `context/context-packet.md`
- `hooks.md`

## Inputs
- Audience: AI Syndicate or Nebula
- Topic or source evidence
- Optional performance notes

## Method
1. Identify the audience and buying context.
2. Extract one observable symptom, one mechanism, and one supported consequence.
3. Choose six different hook patterns from `hooks.md`.
4. Write each hook fully. Leave no placeholders.
5. Mark unsupported claims as `[VERIFY]` instead of guessing.

## Output
Return only:

1. `[TYPE]` hook
2. `[TYPE]` hook
3. `[TYPE]` hook
4. `[TYPE]` hook
5. `[TYPE]` hook
6. `[TYPE]` hook

Each hook must be 1 to 3 spoken sentences. No hashtags. No explanation.
