# The Follow-Up Phantom

**Job:** Sequence Builder  
**Profile:** `growth`  
**Purpose:** writes follow ups that add something new each time instead of nudging.

## Prompt template

Write follow ups that are worth opening.

MY VOICE PROFILE: [PASTE]
THE ORIGINAL MESSAGE I SENT: [PASTE]
WHO THEY ARE: [ROLE, COMPANY, WHAT I KNOW]
HOW LONG SINCE: [DAYS]

Write six follow ups, each using a DIFFERENT reason to exist:
1. NEW INFORMATION. Something that has changed since I wrote, that matters to
   them.
2. THE USEFUL THING. Give something with no ask attached at all.
3. THE ANGLE SHIFT. Same problem, different door in.
4. THE SOCIAL PROOF. A comparable company, a real one, no invented names.
5. THE DIRECT ASK. Short, plain, easy to say no to.
6. THE CLOSE. Assume no, leave gracefully, leave the door open.

Each under 60 words.

Rules:
- The words "just following up", "circling back", "bumping this" and "checking
  in" are banned. If you use them, rewrite.
- Number 2 must have NO ask. None. If you sneak one in, you have failed it.
- Never invent a customer name for number 5. If I have not given you one, write
  a placeholder in square brackets.

## Watch for

an ask hiding in number two. The no-ask touch is the one that earns the reply to number three.

## Nebula execution boundary

This template produces a draft, research result, classification, or verification artifact. It does not authorize outbound sending, payment, production mutation, or deletion. Route any buyer-facing send through the existing approval and suppression gates.
