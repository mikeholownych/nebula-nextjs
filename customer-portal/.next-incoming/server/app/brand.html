06 - Usage Rules

Approved & Prohibited

The mark is a precision instrument. Treat it with the same care as diagnostic equipment - no decorative embellishment, no arbitrary modification.

Approved Usage

  • Use the mark on dark backgrounds with adequate clearspace.
  • Use Nebula Chartreuse (#c7ff2f) as the only chromatic accent in brand contexts.
  • Refer to the product as 'Nebula' or 'Nebula Components'.
  • Maintain minimum 1× mark-width clearspace around the mark.
  • Use the monospace stack for scores, data, and technical labels.

Prohibited

  • Modify the grid pattern or change individual node colors.
  • Use the mark on backgrounds that reduce contrast below WCAG AA.
  • Animate the mark in ways that change node states without reflecting real audit data.
  • Refer to us as a 'CRO agency' or 'landing page optimization service'.
  • Apply excessive glow, drop shadows, or 3D transforms to the mark.
  • Use the mark at sizes below 12px without the small-size variant.

Reduced Motion

When prefers-reduced-motion: reduce is active, all animations collapse to instant transitions (≤0.01ms). Scan lines, ring rotation, and counter animations are disabled entirely. Hover state changes remain but without duration.
