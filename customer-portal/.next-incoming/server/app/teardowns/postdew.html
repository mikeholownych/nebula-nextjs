Five Findings

Ranked by observable priority. Each finding includes the evidence Nebula used - no opinion, no estimation. Priority scores are rule-based heuristics for fix order, not predicted conversion loss.

Finding 1

No Static H1 Detected

Priority 4/10Quick Win

No <h1> tag was found in the fetched document. If the primary promise is rendered only through client-side code, non-JavaScript readers and some extraction systems receive no primary heading.

Evidence

Fetched source: h1 count = 0. Page title: "PostDew - Protect your LinkedIn credibility". Snapshot timestamp: 2026-08-03T07:38:26Z.

Recommended Fix

Render one descriptive H1 in the initial HTML and align it with the credibility promise already present in the title.

Finding 2

No Source-Level CTA Candidate

Priority 4/10Quick Win

No button or link text was found in fetched source HTML. Client-rendered controls may still exist, so browser validation is required before calling this a visible CTA failure.

Evidence

Fetched source: no button or link text candidate. Rendered primary journey remains unverified. Snapshot timestamp: 2026-08-03T07:38:26Z.

Recommended Fix

Inspect the rendered mobile and desktop hero. Make the first action explicit and tie it to the buyer outcome without inventing a performance promise.

Finding 3

No Static Trust Markers

Priority 3.5/10Quick Win

No testimonials, reviews, named proof, or other recognized trust markers were found in the fetched source. An early product may not have customer proof yet; the absence should be treated as a constraint, not a reason to fabricate proof.

Evidence

Fetched source trust terms: none; recognized proof markers: none. Snapshot timestamp: 2026-08-03T07:38:26Z.

Recommended Fix

Use honest process proof first: a sample transformation, transparent product demo, or clearly labeled beta feedback. Add customer proof only when it exists.

Finding 4

Ad Tracking Not Observed in Static Source

Priority 4/10Major Project

No recognized ad-tracking artifact was observed in fetched source HTML. Runtime or server-side tracking remains unknown.

Evidence

Not observed: Facebook Pixel initializer, GA4 measurement ID, UTM-bearing link, or explicit conversion call. Snapshot timestamp: 2026-08-03T07:38:26Z.

Recommended Fix

Validate the actual event path in a consent-aware browser before deciding whether tracking is missing or simply implemented outside the static document.

Finding 5

No JSON-LD or Canonical Detected

Priority 2/10Major Project

The static page has Open Graph tags but no valid JSON-LD block and no canonical URL was detected. This is a machine-readable structure gap, not proof of absent search visibility.

Evidence

Valid JSON-LD blocks: 0/0; Open Graph tags: 5/5 non-empty; canonical: absent. Snapshot timestamp: 2026-08-03T07:38:26Z.

Recommended Fix

Add only accurate Organization/WebSite schema and a self-referencing canonical URL. Validate the JSON-LD after deployment.
