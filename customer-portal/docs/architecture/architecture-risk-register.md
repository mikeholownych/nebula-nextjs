# Architecture Risk Register

**Assessment date:** 2026-08-20
Severity: P0 = correctness / production integrity; P1 = reliability / scale; P2 = performance / maintainability; P3 = cleanup.
Likelihood is conditioned on **current** traffic (single-digit audits/day) **and** a 10× burst or a motivated attacker on the public origin.
