# Acquisition Decision Review Cadences & Epistemic Framework

## 1. Epistemic Separation Rules

Every decision review report generated by the system strictly segregates its content into four distinct epistemic tiers:

1. **FACT**:
   - Verifiable, immutable quantitative measurements from external APIs (Google Search Console, Google Analytics 4, internal payment ledger).
   - Exact dates, URLs, row counts, HTTP statuses, and active holdout states.
   - Example: *"GSC Total Impressions: 1,072 across 41 visible pages."*

2. **DETERMINISTIC INFERENCE**:
   - Mathematical classifications derived deterministically from pre-registered rulesets without statistical extrapolation.
   - Example: *"Search presence is newly established (previous window impressions = 0)."*

3. **RECOMMENDATION**:
   - Actionable hypotheses evaluated against evidence sufficiency gates for human review.
   - Example: *"Sitewide: OBSERVE (maintain stable route structure during initial indexing)."*

4. **LIMITATION**:
   - Explicit boundaries of empirical certainty, missing telemetry, small-sample warnings, and attribution constraints.
   - Example: *"Zero clicks at position > 20 is expected distribution behavior, not evidence of copy deficiency."*

## 2. Review Cadences

### 1. Weekly Decision Review (7-Day Operational Cadence)
- **Purpose:** Operational pipeline health, data completeness validation, active experiment holdout verification, and candidate triage.
- **Output Document:** `docs/acquisition/observations/YYYY-MM-DD_weekly_decision_review.md`
- **CLI Command:**
  ```bash
  uv run python scripts/acquisition_cli.py decision-review-weekly --measurement-id meas_20260830_canonical_w28
  ```

### 2. 28-Day Longitudinal Decision Review (Monthly Cadence)
- **Purpose:** Comprehensive comparison between the current finalized 28-day window and the preceding adjacent 28-day window.
- **Key Metrics Evaluated:** GSC impressions, clicks, dimensionless average position, dimensioned weighted position, visible pages, visible queries, organic sessions, purchases.
- **Output Document:** `docs/acquisition/observations/YYYY-MM-DD_28d_decision_review.md`
- **CLI Command:**
  ```bash
  uv run python scripts/acquisition_cli.py decision-review-28d --measurement-id meas_20260830_canonical_w28
  ```

### 3. 84-Day Strategic Decision Review (Quarterly Horizon)
- **Purpose:** Long-term trajectory evaluation across 3 consecutive, non-overlapping 28-day canonical windows (84 days total).
- **Sufficiency Requirement:** If fewer than 3 non-overlapping 28-day canonical windows exist, the system deterministically outputs:
  ```text
  ## Strategic Status: STRATEGIC_TREND_NOT_ESTABLISHED
  - Required History: 3 consecutive non-overlapping 28-day canonical windows (84 days total).
  - Assessment: Insufficient canonical history to establish long-term strategic trajectory. No strategic pivot or mass page retirement is justified.
  ```
- **Output Document:** `docs/acquisition/observations/YYYY-MM-DD_84d_strategic_review.md`
- **CLI Command:**
  ```bash
  uv run python scripts/acquisition_cli.py decision-review-84d --measurement-id meas_20260830_canonical_w28
  ```
