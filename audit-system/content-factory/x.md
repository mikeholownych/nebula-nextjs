# X (Twitter) Script Format

## The Constraints

- Under 240 characters
- Standalone — makes sense without context
- No hashtags
- Does not end with a question mark
- Contains a specific number or named thing

---

## Worked Examples

**CTA finding:**
```
"Get Started" converts at 1.8%. "Run my free teardown" converts at 3.4%.
Same traffic. Same ad. Six words changed. Specificity is a conversion strategy.
```

**Missing title tag:**
```
Missing meta description = Google writes your SERP description from random body copy.
Saw one SaaS page show "© 2023 All Rights Reserved" as its search result.
0.4% organic CTR.
```

**Social proof:**
```
Added one customer Slack screenshot above the fold.
Conversion went from 2.1% to 2.9%.
It wasn't a good testimonial. It was just proof another human had used the product.
```

**Mobile viewport:**
```
<meta name="viewport"> is one line of code.
Without it, your mobile page renders at 980px and scales down.
Your CTA button is 3mm tall. Your bounce rate shows it.
```

## Thread Format (for finding → thread)

When a finding is strong enough for a thread:

```
Tweet 1: The hook — specific, number-based, pattern interrupt
Tweet 2: What most people assume (wrong answer)
Tweet 3: What's actually happening (the measured finding)
Tweet 4: The cost calculation — ad spend × conversion delta × 12 months
Tweet 5: The fix — exact, one sentence
Tweet 6: How to verify it's fixed
```

## Voice Checklist

- [ ] Under 240 characters (or structured as thread)
- [ ] Contains a specific number or named element
- [ ] No hashtags
- [ ] Last character is not "?"
